# AI CRM 线索评分助手

> 基于 Coze/Dify 搭建的 AI 营销 Agent：RAG 知识库 + 多步骤工作流编排 + 可交互网页 Demo，用于售前需求验证。
> **在线 Demo**：https://ai-crm-lead-scoring.app.workbuddy.host/

## 项目能做什么

输入一条客户线索（行业 / 规模 / 岗位 / 行为 / 留言），AI 自动完成：

1. **透明评分**：属性分(45) + 行为分(25) + 意图分(30)，每项得分可追溯；
2. **自动分级**：≥60 SQL（销售立即跟进）· ≥30 MQL（培育池）· <30 无效（自动过滤）；
3. **生成话术**：基于 RAG 知识库生成个性化跟进消息，答案有出处、不瞎编。

## 快速开始

### 1. 在线体验（0 分钟）
打开 Demo 链接，点击 3 条预置线索（SQL / MQL / 无效）查看完整评分过程与自动动作。

### 2. Dify 一键导入（5 分钟）
```
Dify → 创建应用 → 导入 DSL → 选择 Dify导入_AI-CRM线索评分助手.yml
→ 4 个 LLM 节点绑定模型 → 知识检索节点绑定知识库 → 发布
```

### 3. Coze 手动搭建（2 小时）
按 `Coze搭建包_AI-CRM线索助手.md` 逐步搭建：含每个节点的提示词、代码、测试用例与调试清单。

### 4. 跑通自动化脚本（2 分钟）
```bash
python 批量跟进消息生成.py 示例客户数据.xlsx 跟进消息输出.xlsx
# 读取客户表 → 按意向等级生成个性化消息 → 写回 Excel 新列
```

### 5. 复现数据分析（1 分钟）
```bash
python 商机数据生成与统计.py
# 生成 300 条模拟商机 → 输出商机数据集_模拟300条.xlsx + 统计结果
```

## 核心设计

| 设计点 | 方案 |
|---|---|
| 评分可解释 | 三段式评分，每个节点输出中间分，销售可申诉 |
| RAG 防幻觉 | 话术仅依据知识库检索结果生成，未覆盖内容标注"需与产品确认" |
| 成本控制 | 条件分支前置，无效线索不进付费 LLM 节点 |
| 数据闭环 | 数据分析定位强/弱信号 → 反哺评分权重（岗位↑ 规模↓） |

## 关键发现（数据分析）

- **角色 > 规模**：采购/IT 负责人 SQL 率是普通员工的 3-4 倍；公司规模只推高平均分；
- **强行为信号**：预约演示 / 试用注册 / 浏览价格页在无效组渗透率为 0；下载白皮书为弱信号；
- **意图直通**：留言出现"API/集成对接"平均 73.6 分，接近 SQL 直通线。

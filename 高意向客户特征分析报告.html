① 意向等级分布

按评分模型自动分级：SQL 70 / MQL 196 / 无效 34

分级前置的价值：销售只需人工跟进 70 条 SQL，人效理论提升约 4.3 倍（300→70）。

② 行业 × SQL 率

SQL 率 = 该行业线索中 SQL 占比（括号内为样本量）

金融、制造业、软件/互联网是绝对主力：三个行业样本占 51%，却贡献了 80%（56/70）的 SQL。零售电商高意向率虽高（97% 为 MQL+），但几乎全是"看看再说"型 MQL。

③ 岗位 × SQL 率

决策角色 vs 执行角色，差距悬殊

采购/IT 负责人的 SQL 率是普通员工的 3~4 倍 —— "谁来问"比"哪家公司问"更能预测成交。

④ 公司规模 × SQL 率

规模推高平均分，但几乎不改变 SQL 率

反直觉发现：公司规模只抬分数、不决定成交 —— 评分模型中"规模"权重可下调 3~5 分，让给"岗位"。

⑤ 行为渗透率对比：高意向组（SQL+MQL） vs 无效组

哪些行为真正"值钱"？深色 = 高意向组渗透率，灰色 = 无效组渗透率

强信号（无效组渗透率为 0）：预约演示、试用注册、浏览价格页 —— 应给高分甚至触发 SQL 直通规则。弱信号（两组差异小）：下载白皮书、官网多次访问 —— 人人都有，不该占高分，否则会"灌水"。

⑥ 留言意图 × 平均总分

括号内为该意图线索数量

「集成对接」数量最少（16 条）但平均分最高 —— 留言一出现 API/对接字眼，基本就是 SQL 级信号，值得单独设直通规则。

⑦ 来源渠道 × SQL 率

渠道质量差异明显，但需注意因果方向

白皮书下载渠道 SQL 率 36% 领先 —— 但这是筛选效应（愿意下白皮书的人本来就更活跃）。落地页加"预约演示"入口可把这种兴趣接住。

📌 五条核心结论

1行业集中：金融 / 制造业 / 软件互联网贡献 80% 的 SQL

三个行业样本占 51%、SQL 占 80%。销售资源应按此倾斜；教育、零售电商以 MQL 培育为主。

2角色 > 规模：岗位是最强属性信号

采购/IT 负责人 SQL 率 40-49%，普通员工仅 12%；而公司规模对 SQL 率影响弱（极差 8pct）、只推高平均分。建议模型把"岗位"权重上调、"规模"权重下调。

3行为分层：三个强信号、两个弱信号

预约演示 / 试用注册 / 浏览价格页在无效组渗透率为 0（强信号）；下载白皮书、官网多次访问两组几乎无差异（弱信号），应降低其行为分权重。

4意图即分层：留言关键词直接对应等级

集成对接 73.6 分 > 询价 63.6 > 约演示 60.4 > 功能了解 42.3。「API/对接」出现即接近 SQL 线，可设直通规则。

5渠道：白皮书下载是当前最优获客渠道

SQL 率 36% 领先其他渠道（18-24%）。建议加大内容营销，并在白皮书落地页加"预约演示"入口承接兴趣。

📝 简历写法（对应加分项 1「数据分析」）

对 300 条客户商机数据按行业 / 岗位 / 规模 / 行为 / 意图 / 渠道六维度做分层统计，定位高意向客户特征：决策角色 SQL 率为普通员工 4 倍、预约演示等强行为信号无效组渗透率为 0；据此反哺评分模型权重设计（岗位↑ 规模↓），输出分析报告支撑售前策略。

数据口径说明（面试被追问时用）：
  • 数据为模拟数据集（seed=42 可复现），用于演示分析方法与口径设计；实际业务中官网留资线索的无效占比会显著更高（大量匿名访客不留资），本数据集均为已留资线索，故无效仅 11.3%。
  • 评分口径与 AI CRM 线索助手工作流一致：属性分(45) + 行为分(25) + 意图分(30)，≥60 SQL / ≥30 MQL / <30 无效。
  • SQL 率 23.3% 为"已留资+已分级"口径，与"官网 UV→SQL"口径不可直接对比。
